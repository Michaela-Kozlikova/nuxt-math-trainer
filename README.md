# 🧮 Nuxt Math Trainer

A math practice application built using the Nuxt framework. This project focuses on practicing addition, subtraction, multiplication, and division in 3 difficulty levels.

## 🛠️ Built With
- **Nuxt 3**
- **Vue.js**
- **CSS3**
